The chat widget's composer error clears itself once its cause is gone, and the Close link next to it is removed. "That image didn't upload" stays visible while a failed image is in the tray and disappears when the visitor removes it. The size, type and count rejections and "That message didn't send" disappear when the visitor types, picks or removes an image, or sends. If a failed image is still in the tray when another notice clears, the upload-failure note comes back.
